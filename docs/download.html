🚀 Beta Version Notice

This beta lacks Apple Developer ID and Microsoft code signing certificates, causing Gatekeeper (macOS) and SmartScreen (Windows) warnings during installation.

These warnings completely disappear when Service Bus Voyager exits beta and enters stable release with full developer certification.

🍎 macOS Installation

When you first open Service Bus Voyager on macOS, you may see a warning that the app "cannot be opened because it is from an unidentified developer."

Example of macOS Gatekeeper warning

Remove the quarantine attribute using Terminal:

xattr -d com.apple.quarantine '/Applications/Service Bus Voyager.app'

After running this command, the app will open without warnings on subsequent launches.

🪟 Windows Installation

When installing on Windows, you may see a Microsoft Defender SmartScreen warning stating "Windows protected your PC."

How to Bypass SmartScreen:

  1. Click More info in the SmartScreen dialog
  2. Click Run anyway button that appears at the bottom
  3. The application will install and run normally
