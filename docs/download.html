⚠️ Installation Warnings (Beta Version)

This version of the application is in beta phase and does not have developer certificates (Apple Developer ID and Microsoft code signing). This causes Gatekeeper/SmartScreen warnings. This is normal for early indie/startup releases — the application is safe and developed by Gruz-Soft, a developer from Poland.

Certification is planned for future stable versions after collecting feedback. Download only from the official website!

🍎 macOS Installation

When you first open Service Bus Voyager on macOS, you may see a warning that the app "cannot be opened because it is from an unidentified developer."

Example of macOS Gatekeeper warning

Solution 1: Using System Settings

  1. Click Cancel in the warning dialog
  2. Open System Settings → Privacy & Security
  3. Scroll down to find the message about Service Bus Voyager
  4. Click Open Anyway
  5. Confirm by clicking Open in the next dialog

Solution 2: Using Terminal

Alternatively, remove the quarantine attribute using Terminal:

xattr -d com.apple.quarantine '/Applications/Service Bus Voyager.app'

After running this command, the app will open without warnings.

🪟 Windows Installation

When installing on Windows, you may see a Microsoft Defender SmartScreen warning stating "Windows protected your PC."

How to proceed:

  1. Click More info in the SmartScreen dialog
  2. Click Run anyway button that appears
  3. The application will install normally

This warning appears because the application doesn't yet have a Microsoft code signing certificate. The app is completely safe to use.
